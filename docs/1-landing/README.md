# AjsCodeVisualizer — landing (tier 1)

A free, installable web app that teaches programming fundamentals through interactive,
language-agnostic visuals. It is built for people who learn by seeing, with ADHD and other
learning differences in mind. It shows how and why each concept works, cites trusted official
documentation, and walks the learner through breaking a task into steps, building it, and proving
it works. The full brief is issue #1.

**Current shape:** documentation only. No code yet — see [state](../3-state/ProjectState.md).
